      - 列名: server_id, 类型: INT UNSIGNED DEFAULT NULL, 位置: AFTER instance_id
      - 外键约束: CONSTRAINT `fk_report_server` FOREIGN KEY (`server_id`) REFERENCES `servers`(`id`) ON DELETE CASCADE

    1.2 report_configs 表增加 server_id 列：
      - 列名: server_id, 类型: INT UNSIGNED DEFAULT NULL, 位置: AFTER instance_id
      - 外键约束: 由于 report_configs 的 instance_id 已有 FK（fk_rc_instance），此处 server_id 可为空，FK 到 servers(id) ON DELETE CASCADE
      - 索引: INDEX `idx_rc_server_id` (`server_id`)
      - 使用 information_schema.COLUMNS 检查幂等

    1.3 report_configs 表修改 type ENUM 值：
      - 当前 type 定义为 `ENUM('health', 'performance', 'slow_query', 'capacity')`
      - 扩展为 `ENUM('health', 'performance', 'slow_query', 'capacity', 'server_health')`
      - 使用 ALTER TABLE MODIFY COLUMN（如果列定义变更，MySQL 5.6+ 支持追加 ENUM 值）
      - 与 configuration 中添加的 server_health 类型保持一致
