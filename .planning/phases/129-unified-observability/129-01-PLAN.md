  <action>
    创建迁移文件 `/apps/db-ops-api/sql/migrations/022_unified_observability.sql`，包含三块 idempotent 操作：

    1.1 metric_definitions 表增加 target_type 列：
      - 列名: target_type, 类型: `ENUM('instance', 'server')`, NOT NULL, 默认值 'instance'
      - 位置: `AFTER id` (与 migration 021 的 alert_rules 模式一致)
      - 使用 information_schema.COLUMNS 检查存在性，幂等执行

    1.2 metric_definitions 将现有 instance 指标的 target_type 批量更新为 'instance'：
      - UPDATE metric_definitions SET target_type = 'instance' WHERE target_type IS NULL OR target_type = ''
      - 仅在首次添加列后执行（可通过 target_type 默认值保证）

    1.3 创建 alert_rule_templates 表：
      - 列: id (AUTO_INCREMENT PRIMARY KEY), name (VARCHAR 255 NOT NULL), description (TEXT), target_type (ENUM('instance','server') NOT NULL DEFAULT 'instance'), metric_name (VARCHAR 100 NOT NULL), operator (VARCHAR 10 NOT NULL), threshold_template (JSON), duration_seconds (INT DEFAULT 60), severity (ENUM('info','warning','error','critical') DEFAULT 'warning'), silence_minutes (INT DEFAULT 5), enabled (BOOLEAN DEFAULT TRUE), created_by (INT UNSIGNED), created_at (DATETIME DEFAULT CURRENT_TIMESTAMP), updated_at (DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP)
      - 索引: idx_target_type (target_type), idx_metric_name (metric_name)
      - 使用 CREATE TABLE IF NOT EXISTS 确保幂等

    1.4 插入 server 预置告警模板（5 条种子数据）：
      - CPU过高: metric_name='cpu_usage', operator='>', threshold_template={"warning":80,"error":90,"critical":95}, duration_seconds=120, severity='warning'
      - 内存过高: metric_name='memory_usage', operator='>', threshold_template={"warning":80,"error":90,"critical":95}, duration_seconds=120, severity='warning'
      - 磁盘过高: metric_name='disk_usage', operator='>', threshold_template={"warning":75,"error":85,"critical":95}, duration_seconds=180, severity='warning'
      - 负载过高: metric_name='load_1min', operator='>', threshold_template={"warning":4,"error":8,"critical":12}, duration_seconds=120, severity='warning'
      - 服务器不可达: metric_name='reachability', operator='=', threshold_template={"warning":1,"error":2,"critical":3}, duration_seconds=600, severity='error'
      - 所有模板 target_type='server'
      - 使用 INSERT IGNORE INTO 防止重复插入（以 name+target_type 为逻辑唯一键，可通过先 SELECT 再 INSERT 或直接使用唯一索引+INSERT IGNORE）

    所有操作包裹在 START TRANSACTION / COMMIT 中。
