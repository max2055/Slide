<task type="auto">
  <name>Task 2: Create ServerAlertEvaluator</name>
  <files>apps/db-ops-api/src/server-alert-evaluator.ts</files>
  <action>
    Create ServerAlertEvaluator extending the existing alert evaluation pattern:

    ```typescript
    import { dbConnection } from './db-connection';
    ```

    **Methods:**

    1. `evaluateServerRules()`: Called on a cron interval (60s, same as existing alert evaluation). For each server where collection_enabled=true:
       - Fetch server alert rules (WHERE target_type='server')
       - Fetch latest metrics from server_metrics
       - For each rule: check threshold against current metric value
       - If breached: create alert + alert_event via existing alert engine patterns
       - Skip rules for servers that have no metrics yet (just registered)

    2. `checkUnreachable()`: Called separately, checks servers where status='unreachable' for more than 2 collection cycles (10 minutes):
       - For servers that have been unreachable for >10min AND have an active server alert rule:
       - Create "服务器不可达" alert via existing engine
       - Only trigger once per unreachable episode

    3. Alerts created by ServerAlertEvaluator set:
       - target_type='server'
       - server_id = the server's id
       - source = 'server-monitor'

    **Integration:**
    - Wire into the existing alert engine cron loop (in monitor-collector.ts or wherever evaluateAllRules() is called)
    - Add import and call evaluateServerRules() alongside the existing DB instance evaluation
  </action>

  </verify>
  <done>
