<task type="auto">
  <name>Task 1: Create ServerReportService</name>
  <files>apps/db-ops-api/src/server-report-service.ts</files>
  <action>
    Create ServerReportService class:

    **Methods:**

    1. `generateReport(): Promise<ReportData>`:
       - Query all servers with their latest metrics
       - For each server: compute health score as weighted avg of CPU (<50%=100, 50-80%=60, >80%=20), memory (same), disk (avg across mount points), load (relative to CPU count — assume 4 cores for now, <1=100, 1-2=60, >2=20)
       - Overall health = avg of 4 dimension scores
       - Return structured: { generated_at, server_count, healthy_count, warning_count, critical_count, servers: [{ host, label, status, cpu_score, memory_score, disk_score, load_score, overall_score, metrics_summary }] }
       - Sort servers by overall_score ascending (worst first)

    2. `generateHtml(reportData): string`: 
       - Format as HTML report with table of all servers with color-coded scores
       - Green (>80), amber (60-80), red (<60) for score thresholds
       - Summary header with counts

    3. `generateMarkdown(reportData): string`:
       - Same data as markdown table format

    **Report scheduling:**
    - The report can be triggered via API or cron job
    - Reuse the existing cron_jobs mechanism (Phase 113) to schedule it
    - Default schedule: daily at 09:00

    **API route:**
    - `POST /api/servers/reports/generate` — verifyToken + requirePermission('servers:manage'), generates and returns the report
    - `GET /api/servers/reports?format=html|md` — generates and returns formatted report
  </action>
  <verify>
    test -f apps/db-ops-api/src/server-report-service.ts && \
    grep -c 'generateReport\|generateHtml\|generateMarkdown' apps/db-ops-api/src/server-report-service.ts
  </verify>
  <done>
    ServerReportService generates health reports with HTML/MD output. API route registered.
  </done>
