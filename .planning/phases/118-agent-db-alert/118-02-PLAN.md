## Plan 118-02: Agent DB 连接工具

### Objective
让 AI Agent 可以通过工具获取数据库实例的连接信息，从而能实际连接到数据库进行分析。

### Background
Agent 当前通过 `@slide/agent-core` 的工具系统工作，已有 `slide-self-mgmt/` 下的工具（check_status, add_database, test_connection 等），但缺少让 Agent 获取连接详情的工具。

Agent 需要能够：
1. 列出所有数据库实例及其基本信息
2. 获取特定实例的完整连接信息（host, port, user, password, db_type）

### Implementation

**Tool 1: `list_database_instances`**
- 路径: `apps/db-ops-api/src/tools/generated/slide-self-mgmt/list_database_instances.ts`
- 功能: 返回所有活跃实例的列表（id, name, db_type, host, port, health_status）
- 权限: 需要认证
- 不返回密码

**Tool 2: `get_instance_connection`**
- 路径: `apps/db-ops-api/src/tools/generated/slide-self-mgmt/get_instance_connection.ts`
- 功能: 返回单个实例的完整连接信息（含解密后的密码）
- 参数: instance_id
- 权限: 需要认证 + agent 权限
- Schema: 返回 { host, port, username, password, db_type, database_name, connection_string }

**Schema 定义**:
- 在 `packages/agent-core/src/skills.ts` 或 `tool-catalog.ts` 中注册工具 schema
- 使用 `ToolSchema` 类型定义工具的输入/输出

### Tasks
1. 创建 `list_database_instances` tool implementation
2. 创建 `get_instance_connection` tool implementation
3. 在 ToolCatalog 中注册新工具
4. 测试 Agent 能否成功使用工具获取连接信息
