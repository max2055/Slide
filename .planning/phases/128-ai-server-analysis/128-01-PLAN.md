  <action>
    Create server-tools.ts following the existing tool patterns in tools/generated/slide-self-mgmt/:

    **Tool 1 — list_server_instances:**
    - Description: "列出所有已纳管的服务器及其基本信息和健康状态"
    - Parameters: none
    - Returns: Array of { id, host, label, port, os_type, status, last_check_at, metrics_summary }
    - metrics_summary includes latest cpu_usage, memory_usage, disk_usage values

    **Tool 2 — get_server_metrics:**
    - Description: "获取指定服务器的指标数据和历史趋势"
    - Parameters: { serverId: number, metricName?: string, range?: '1h'|'6h'|'24h'|'7d'|'30d' }
    - Returns: { server info, latest metrics, history (if range specified) }

    **Tool 3 — get_server_alerts:**
    - Description: "获取指定服务器的告警信息"
    - Parameters: { serverId: number, activeOnly?: boolean, limit?: number }
    - Returns: Array of alerts for this server

    **Tool 4 — analyze_server_health:**
    - Description: "分析指定服务器的健康状态，生成诊断摘要"
    - Parameters: { serverId: number }
    - Returns: { overall_health, cpu_analysis, memory_analysis, disk_analysis, recommendations }
    - This tool queries latest metrics and generates a structured health analysis

    **Registration:**
    - Export tools array
    - Import and register in tool-registry.ts following existing pattern
  </action>

  </verify>
