<threat_model>
| Threat | Mitigation |
|---|---|
| 离线恢复导出的凭据 | 不返回密文；生产 secret 强制且版本化 |
| LLM 输出脚本 | Lit escaped binding + DOMPurify allowlist |
| webhook 探测内网/元数据服务 | DNS 与每跳目标校验，默认无重定向 |
| 错误信息二次泄密 | 结构化 reason code，日志与 DTO 脱敏 |
</threat_model>
