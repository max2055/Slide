    - `_openAddDialog()`: reset form, this.testResult = null, this.editingServer = null, this.dialogOpen = true

    - `_deleteServer(s)`: if confirm(`确定删除服务器 ${s.host}?`), DELETE /api/servers/:id, then _loadServers()

    - `_testConnection()`: Build credential body from form.this.form.credential_type, this.form.username, and either this.form.password or this.form.privateKey. POST /api/servers/test-connection. Set this.testResult = result. Per D-09: simple pass/fail with error details on failure.
