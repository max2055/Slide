Slide 项目结构

本仓库采用 pnpm workspace 管理前端、后端和可复用 Agent Core。下列目录说明以当前代码为准，不包含构建产物、测试报告和本地运行状态。

顶层目录

.
├── apps/
│   ├── db-ops-api/       # Fastify API、控制面服务与运维引擎
│   └── db-ops-skills/    # 预定义运维技能包
├── frontend/             # Lit 3.3 + Vite 控制台
├── packages/
│   └── agent-core/       # AgentRunner、会话、工具与 LLM 抽象
├── docs/slide/           # 应用内文档的 HTML 发布文件
├── scripts/              # 发布与回滚演练脚本
└── tests/qualification/  # 发布资格与覆盖矩阵检查

后端：apps/db-ops-api

位置职责
server.ts服务入口：迁移、HTTP 路由、Worker lease、DirectAdapter、采集器、告警与工作流启动。
src/adapter/DirectAdapter、LLMProvider 适配、平台工具加载和 Agent 引擎工厂。
src/auth/JWT、Actor Context、RBAC 与安全边界。
src/adapters/受管数据库类型和能力矩阵。
src/collectors/、src/resources/统一指标采集、能力跟踪和资源观测。
src/alerts/、src/operations/、src/workflows/告警事件、操作状态机、通知和持久化工作流。
src/cron/脚本、定时任务、Agent 驱动的 Cron 执行器和运行日志。
src/llm/、src/prompts/、src/skills/提供商目录、提示词版本和技能加载。
src/security/控制面安全配置、数据库目标限制、出站通知策略和审计防护。
sql/migrations/控制面 Schema 的版本化迁移。

前端：frontend/src

位置职责
api/认证请求封装和生成的 API 类型。
app/ui/应用外壳、导航、主题、共享组件和页面视图。
app/ui/views/仪表盘、实例、服务器、SQL、告警、审批、报告、定时任务与设置页面。
app/ui/chat/、app/ui/sessions/DirectAdapter 会话、消息流、历史记录和运行状态。
app/i18n/中英文界面文案及运行时语言设置。
app/styles/设计 token、共享按钮和布局样式。

Agent Core：packages/agent-core

该包不包含平台业务路由。它提供 AgentRunner、消息和工具类型、会话与上下文管理、LLM Provider 接口以及运行时钩子。后端的 DirectAdapter 负责把这些能力接入 Slide 的认证、审计和工具策略。

文档与契约

  • docs/slide/*.html：登录后在控制台的“文档”中显示。
  • docs/slide/openapi.json：公开 API 契约的生成产物；通过 pnpm contracts:generate 更新。
  • apps/db-ops-api/tests/ 与 frontend/e2e/：后端行为和用户交互的验证用例。
