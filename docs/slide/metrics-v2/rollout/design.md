## 推荐设计

### 正式来源与回退

以资源类型/ID＋指标语义版本＋排序维度为身份，记录唯一正式来源及单调递增切换代次。影子采集允许保留证据，但不得同时发布正式值或触发正式告警。旧/新写入与正式消费都必须在同一控制边界校验来源和代次，不能仅依靠测试内 Map 或 UI 开关。

切换顺序：先停止旧来源新增任务，等待在途收敛；原子更新来源代次与读模式；新来源通过应用确认后放量。旧代次迟到结果可留影子证据，但不得覆盖正式状态。未收敛或 CAS 冲突则保持原正式来源并停止放量。包 published/applied revision 与来源代次分别记录，不能相互替代。

回退采用新代次恢复旧包 pin/兼容读路径，保留 V2 表、观测和 Raw 证据；不回减 revision、不执行 DROP、不把 V2-only 数据伪造回旧列。回退后旧值陈旧必须显示真实时间。演练脚本仅接受明确隔离数据库，输出当前/目标状态并检查预期代次；最终报告给出经实际执行验证的命令。

### 告警转换幂等

复用现有评估与告警服务，以资源、规则及规则版本、指标/维度、固定窗口和目标状态构造转换键。通过数据库唯一约束及事务保证转换记录与告警状态写入共同提交；并发重复、恢复后重放旧窗口、worker 重试均不能重新创建同键状态转换。未知质量不触发恢复。来源/revision 信息作为证据保存，切换不能无条件制造新告警身份。

若现有服务已满足某个原子边界，直接复用并补回归；只在实测缺口处新增最小迁移和调用接线。通知继续使用既有机制，不声称 SMTP 或外部系统投递 exactly-once。

### 三类代表与证据分层

数据库使用 MySQL 代表计数/速率；Host 使用 Linux CPU/内存代表指标；SNMP 使用带接口维度的计数器/速率。复用既有包和 collector fixture，同步比较 Raw、Normalized、Aggregation、统一查询及告警消费。

每项证据标明：契约 fixture、模拟端点、真实 MySQL 持久化/Worker/HTTP，或真实目标采样。模拟 SSH/SNMP 不冒充实机。必须取得三类闭环证据，实机覆盖不足作为发布限制单列；隔离必需测试失败不得用环境说明替代通过。

差异表记录旧/新值、单位、口径、质量、采样窗口、版本血缘、逻辑读取数、耗时和字节数。同语义跨模板可比；非等价映射拒绝；Counter 首点/reset/wrap/缺失不伪造正常速率。Canonical/Extension 使用同一质量规则，CoreProfile 在包切换前后稳定。

### 容量和灰度阈值

从隔离清单实际资源数、实际发现维度、实际周期计算各类点数；不把指标名数量当序列数。分别计入 Raw、Normalized、attempt、tombstone、索引、备份及保留期。实测存储字节、采集耗时、写入/查询 p50/p95/p99、错误率和峰值并发，并把公式外推与实测容量分开。

隔离负载采用固定随机种子、明确资源/维度阶梯和有限轮次；不能无界放量。最低放行要求：正式来源冲突/重复转换/错误映射为 0，相关验收全部通过，无未解释值差异，采集 p95 小于配置周期且不超过 timeout，峰值序列数不超配置预算。吞吐以峰值需求的 2 倍做隔离压力目标；容量按保留需求加至少 30% 余量。无法满足则报告 no-go，不调整指标隐藏失败。

先三类各一测试资源，再扩大隔离资源集合；每级检查上述阈值，失败自动停止升级并执行经验证的保留数据回退。

## 验收矩阵与验证顺序

| 验收 | 可核验产物/断言 |
| --- | --- |
| 三类影子差异 | 原始 JSON 证据、差异表、转换/聚合版本及时间窗口 |
| 语义与消费兼容 | 跨模板等价对比、非等价拒绝、CoreProfile、旧阈值/评分回归 |
| 唯一来源 | 两个竞争来源同时提交仅一方正式可见；CAS 冲突、旧代次迟到拒绝 |
| published/applied | 发布后 pending，实际应用后更新；过期 revision 不得提交 |
| 告警重放 | 同键并发/串行重放仅一次转换，恢复后旧窗口不可再触发 |
| 故障与接管 | 超时、权限失败、断连、显式租约过期、旧 owner 拒绝、新 owner 成功 |
| 保留/回退 | Raw available→expired，清理幂等；包/读路径回退且数据仍存在 |
| 容量 | 实际清单、维度基数、有限负载结果、预算公式和 go/no-go |
| 交付 | 环境与覆盖矩阵、剩余风险、可复现命令、PR/commit |
