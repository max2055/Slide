# MAX-36 v3：数据库图表与布局优化验收

用户截图反馈对应的 v3 范围记录位于 `docs/superpowers/plans/2026-09-11-compact-overview.md`，基线 a8a218d，追加到未合并 PR #39。未改全站主题、采集器或自动诊断。

## 结果

- 数据库类型占比按当前搜索/引擎范围内的实例数量计算，饼图配有数量、百分比和可用键盘操作的图例。
- 总数据量折线图默认合计当前筛选实例，保留单实例、24h/7d/30d/日期范围和 URL 恢复。接口增加 `instance_ids`（最多 500 个唯一 ID），逐个执行已有实例访问权限检查；空值、非法值、超限与同时提供单实例参数返回 400，越权返回 403。
- 历史容量按每实例每小时最后样本求和，不把缺采样补零；小时缺口和采样覆盖数量变化断线，显示实际观测时间及覆盖数。最近覆盖不足时标题数值标记“已采集”，不冒充完整总量。
- 搜索改为“搜索资源”，提示“名称、地址或资源 ID”，采用行内标签并紧靠视图切换。数据库图表移到 KPI 下；风险、指标、明细连续排在主列，右侧状态摘要独立，避免后续内容被较高侧栏整体推低。隐藏无内容的卡片 footer。
- 修复容量图实际不可读的根因：总览通用 SVG 图标尺寸规则将 ECharts SVG 压成 20px。浏览器新增宽度断言先失败，再通过图表专用尺寸覆盖修复；关闭图表入场动画，避免读取或截图时只显示半成品曲线。
