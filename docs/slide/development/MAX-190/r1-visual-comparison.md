# R1 与产品组件对照

设计依据为用户批准的 R1，确认及冻结 SHA 见 `verification-checkpoint.md`。产品截图由 Playwright 挂载真实 Lit 组件、使用受控 API 生成；**不是实服务业务验收**。

| 页面 | 对齐内容 | 真实数据适配与边界 |
|---|---|---|
| 编辑桌面 | 页内两页签、主列／290px侧栏、推荐与覆盖、对象开关、间隔与策略组、高级覆盖和操作区 | 保留原覆盖方式与自定义值；间隔显示继承的当前值；策略组使用搜索＋可见项选择，不自由填写 ID |
| 编辑窄屏／深色 | 单列堆叠、主题 token、控件换行和无整页横向溢出 | 侧栏保留五层事实与真实未知时间，信息量比演示更多 |
| 连续启用 | 共享 app-dialog 中四阶段、真实预检／试采／发布动作、权限和全局阻塞 | 本次流程步骤与当前已生效配置分别表达，不从应用成功伪造试采或正式样本 |
| 详情 | 当前事实三列、覆盖质量和配置事件双列，窄屏堆叠 | 事件来自权限过滤审计 API；正式 pending 明确为等待正式数据；不把未知开关显示成停用 |
| 全局模板 | 共享表格、筛选、查看模板详情弹窗；模板语义版本保留 | 未提供绑定对象计数则不显示演示数字；模板覆盖列来自真实目录映射，详情保留权限／发现方式／推荐参数 |

外层原型审阅工具栏、演示侧栏和演示工作区不复制进产品。现有策略组管理与权限保护保留；服务器／网络设备的页内宿主待 MySQL 正常实服务对照通过后推广。当前截图可用于组件布局核对，不足以批准最终业务交付。

证据包的 `comparison.html` 把冻结原型截图与本次产品组件截图并列展示；`screenshots/` 保留完整明暗／桌面窄屏与异常矩阵。所有图片在 HTML 中内嵌，不依赖本地路径或审阅服务器存活。
