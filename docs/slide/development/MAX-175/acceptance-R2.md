## 真实服务证据与受控证据

真实服务测试使用任务独占 MySQL 8.4、完整迁移、正式完整 Fastify 服务、真实 JWT 和实时权限 API、Vite 应用壳。数据库库存、55 条日志、服务器与网络库存和两条接口记录为测试持久化预置；未模拟正常 API 响应。定时采集禁用；服务器夹具的 `os_type='Linux'` 不属于支持的发行版，诊断 GET 在凭据读取和 SSH 连接前返回 422 `HOST_OS_UNSUPPORTED`。没有连接线上 SSH/SNMP/数据库目标，不改共享 Provider、binding 或服务。

- 数据库概览/指标/日志：1440/768/390 × 明暗。日志首批 50 条、第二批 5 条，ID 集合不相交；每组实际 ID 记录在 `database-real-service.json`。范围/等级回首页、关键字无匹配仍能翻批、键盘全文均验证。
- 服务器概览/指标/日志与网络概览/指标/接口/备份：同样覆盖三视口明暗。正式接口 API 读取真实保存记录，名称/状态筛选生效；服务器日志呈现真实诊断加载失败（422），不能作为空日志或正常日志验收；语义指标为真实未配置。
- 受控补充：概览正常/空/加载/失败/无权/部分/过期/冲突，共48图及撤权；指标比较、筛选、趋势断点、定义与原始详情键盘操作，共6图；日志和接口的空/加载/失败/无权，共48图。命名均带 `controlled-`，不混为真实目标正常采集。
