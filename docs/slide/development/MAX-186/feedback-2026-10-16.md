## 用户反馈整改

本轮按用户提供的六张截图，对五类共性问题统一整改。设计依据是现有应用壳、数据库表单的关闭行为及共享组件规范；不更改业务能力或资源权限。

| 验收项 | 实施与覆盖 |
| --- | --- |
| 蓝底黑字 | 保留用户强调色用于链接、边框与轻背景；新增填充色 token，根据强调色降低亮度直到白字对比度 ≥4.6:1。共享主按钮、头像，以及告警列表/详情、事件、报表、数据库日志、索引、审批等独立填充按钮统一使用。悬停不再降低整颗按钮透明度。显式保存的自定义按钮配色继续优先。 |
| 列表紧贴操作区 | 关注事项操作区增加 space-lg 顶部间距；共享资源表格的工具、内容、分页分别留出 space-md，空态/加载/权限状态保持原语义。 |
| 遮罩误关 | app-dialog 默认不因遮罩点击关闭；调查创建和批量审批移除空闲时允许误关的覆盖。显式取消、关闭、Esc、焦点循环/恢复继续保留；提交中的锁定不变。 |
| 下拉框 | 全局和 Shadow DOM 共用单选框样式，箭头距右边 12px，文字预留 36px；资源/调查状态筛选桌面宽 140px，窄屏自适应。多选/listbox 和强制色保留原生表现；app-select-field 补齐 label 关联。 |
| 三类资源布局 | 数据库卡片改为与网络设备相同的紧凑容器；共享资源表格负责内部 padding，与服务器/网络/数据库的工具条对齐。桌面 space-lg、窄屏 space-md，并沿用户密度缩放；宽表保持局部滚动。 |

复核中同时修复了事件中心长资源名跨列覆盖：名称在单元格内截断，保留完整 title 和原导航。

排查同时覆盖共享样式之外的独立 `.action-btn.primary`、`.btn.primary`、填充徽标和 hover 状态，避免仅修截图中的两个按钮。单选框样式补入既有 Shadow DOM 的规则编辑、列表浏览、资源配置、治理、设置等消费者，不迁移 DOM 封装。
