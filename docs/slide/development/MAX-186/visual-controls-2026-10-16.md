## 目标与设计依据

落实 Max 在 MAX-186 评论 `01a1443b-65bf-77bc-8ff0-a5ba4b95a95a` 提出的按钮与主要元素一致性反馈。沿用已确认的应用壳、R1.1 和 frontend/AGENTS.md 的共享组件规范；不改变业务动作、权限、路由、后端契约或用户保存的外观偏好。

采用共享样式并迁移消费者：只在截图涉及的三个按钮补样式无法防止其他页面继续分叉；重建独立组件/主题则会扩大兼容成本。普通 DOM 和 Shadow DOM 使用同一份 CSS，已有类名/尺寸别名继续兼容。

## 按场景执行的规范

| 场景 | 实现 | 规范 |
| --- | --- | --- |
| 页面/列表工具栏刷新 | `btn btn-refresh` | 次要背景、文字与边框；统一 16px 双向刷新图标；图标与文案间隔 6px。刷新不因加载变成主操作。 |
| 创建、保存、提交 | `btn-primary`，兼容 `btn primary` | 使用主按钮配色；同一操作区只突出必要主要动作。 |
| 筛选、取消、返回、列设置 | `btn` | 次要样式；不能各页自行定义一套圆角、字体和配色。 |
| 表格行内编辑/查看 | `btn-sm` / `btn-ghost` | 紧凑尺寸；hover 不提升成蓝色填充主按钮。 |
| 删除 | `btn-sm danger` / `btn-danger-outline`；确认用 `btn-primary btn-danger` 或 `btn danger` | 危险语义独立，确认动作与普通刷新不混用；保留现有二次确认。 |
| 卡片标题、聊天工具栏图标 | `btn-icon` 或现有聊天紧凑图标按钮 | 因场景不同可以紧凑、仅图标；提供可访问名称，不能把页面级刷新随意做成仅图标。 |
| 加载/禁用 | 原生 disabled；实际加载时 aria-busy | 保留原处理器/状态，统一禁用透明度；刷新图标旋转，系统减少动态效果时停止旋转。 |

标准按钮 `--control-height=40px`，行内按钮 `--control-height-sm=28px`，随现有密度按 0.85/1/1.15 缩放（34/40/46px、24/28/32px）；文字分别消费 `--text-md` / `--text-sm`。圆角使用 `--radius-sm`；窄屏/粗指针最小高度 44px。宽度跟随文案，不要求不同文案等宽。

## 主要元素与外观入口

| 元素 | 共享入口 | 排查与处理 |
| --- | --- | --- |
| 按钮 | `shared-btn-styles.css` / TS wrapper | 删除普通 DOM 和多个页面的重复通用按钮定义；两类 DOM 共用源文件。旧类名兼容；清理独立 action-btn 和刷新覆盖。 |
| 表单、下拉框 | app-form-field、app-select-field、shared-field-styles | 保留已完成的标签关联、统一箭头和误关保护；app-select-field 的字号、间距、高度改用密度 token。 |
| 卡片 | app-card | 保留共享边框/圆角/头部/页脚及 compact 模式；不把表格容器和内容卡片强行变成同一布局。 |
| 表格/分页 | app-data-table、resource-metrics-table | 保留局部滚动、工具/结果/分页间距；移除行内按钮的重复尺寸覆盖。 |
| 徽章 | app-badge | 保留状态语义、主题配色；辅助字号消费 token，跟随密度。 |
| 统计卡 | stat-card | 字号/间距由硬编码改为对应现有 token，保留桌面/窄屏层级和含义，不修改统计事实。 |
| 弹窗/空态 | app-dialog、app-empty-state | 复用现有共享实现，保留关闭/Esc/焦点、无数据/失败/权限语义；本轮复用相关回归。 |

外观已有按钮分类配色、强调色、字体密度、圆角及持久化。此次直接使用这些配置，补充场景说明及真实尺寸刷新预览；没有新增一套“刷新颜色/尺寸”偏好，也不覆盖已保存的定制。配色可跨 Shadow DOM 继承；页面不再覆盖共享按钮 palette。高对比和减少动态效果沿系统设置处理。

## 排查范围与验证边界

源码扫描覆盖 frontend/src 下 99 个含按钮的生产文件、608 处按钮模板；清单随证据附件提供。静态模板数量不是页面运行数量。统一 38 个文件的 40 处刷新模板（包括三类列表、详情、总览、关注事项、治理/审计/工具页、资源局部证据等）。同步源码、重新计算、重试与重新连接保留其不同业务含义；聊天仅图标刷新保留紧凑场景。

浏览器回归检验普通 DOM/Shadow DOM 样式一致、明暗主题、三种密度、1440/390、显式按钮 palette、圆角、hover、焦点、禁用、减少动态效果与强制色。正式 Fastify＋独立 MySQL＋密码登录/JWT 对总览、数据库、服务器、网络设备、关注事项、Agent 工具、健康页的页面/列表刷新比较计算样式，并点击刷新读取原业务端点；前轮六页面表单及资源间距回归保留。

数据均为明确标注的隔离持久化合成数据，不代表真实采集或 Max 已完成业务验收。共享5173仅更新用户已授权的前端候选，后端/Provider/采集不变；不代取共享会话，不调用产品模型。最终测试结果和确切候选/运行版本在本轮交付记录及附件中报告。
