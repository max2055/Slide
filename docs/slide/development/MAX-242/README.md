## 原型说明

`prototype/index.html` 是独立静态页面，不引入生产前端构建、不请求后端、不调用模型：

```bash
# 直接打开即可；也可用任意静态服务器
open docs/slide/development/MAX-242/prototype/index.html
```

- 所有页面顶部常驻“演示数据 · 未接真实后端 · 不调用模型”标识；故事数据带 `[样例]` 前缀。
- 覆盖故事：事件进入 → 自动上下文 → 启动确认 → 只读排查 → 结构化补充 → 下一轮结果版本 → 行动草案 → 独立审批 → 显式执行 → 三类复测；另有平台异常故事与异常分支面板。
- 原型仅验证交互与信息层级，不证明采集、权限、审批、执行或恢复能力已经可用。
