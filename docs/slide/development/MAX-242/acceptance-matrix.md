# MAX-242 验收矩阵

本矩阵把 Issue #266 的六项验收与少输入设计验收拆到可执行判定。**状态含义**：
- `已有`：当前代码存在对应机制，并有可定位证据；
- `部分`：机制存在但缺输入/展示/分支，需实现补齐；
- `缺失`：无对应实现；
- `未验证`：真实业务闭环依赖 MAX-238/239/240 P1 证据，本轮无法运行。

> 本轮仅完成设计与盘点。任何一项都不因原型或单测判为通过；`in_review` 的判定仍需实现后的真实闭环证据。
