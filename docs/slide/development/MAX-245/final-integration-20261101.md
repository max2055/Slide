## 本轮文件系统能力边界

新增 `linux-filesystem-discovery@1.0.0`，正式指标 `linux.filesystem.discovered_used_bytes` 是 `(f_blocks-f_bfree)*f_frsize` 已使用字节，非使用率/可用字节，不修改既有包或版本摘要。

固定只读 SSH Python 命令读取完整 mountinfo，校验唯一根挂载、前后清单一致、挂载路径实际设备相符，再读取 statvfs。仅发现 ext4/xfs/btrfs/tmpfs 的文件系统根，排除 /proc、/sys、/dev 及子树、bind 子根、子卷根和其他类型，最多100行且受模板更小预算约束。缺 Python3/f_fsid、权限不足、缺行、截断、超时、清单变化或重复 FSID 根均返回失败/未知，不伪装完整空枚举。

身份由 boot、挂载命名空间、设备号、类型、原生 FSID 组成，mount 路径和 mount ID 只作显示。路径移动保持身份；重启/命名空间变化属于新的内核生命周期。这里不是跨主机持久磁盘 UUID 或所有发行版/文件系统认证；不能保证未知内核实现的 FSID 永不复用。发布端强制 filesystem_epoch 作为稳定身份维度，拒绝用路径代替。

真实夹具在自有 Linux 容器创建 tmpfs、写入数据、移动路径，以 open_tree/move_mount 保持同一存活文件系统隐藏/重现，再真实卸载并重建。受控 SSH 端点执行真实握手、认证和主机密钥校验，仅接受注册固定命令；不是 OpenSSH 部署。注册 Linux 族用既有 CentOS 元数据，命令实际运行于冻结 Python/Alpine 镜像，不宣称 CentOS 发行版实测。
