# 三类完整资源详情设计

目标：列表“详情”进入**完整资源观测**，保留每类既有专业能力；共享身份、时间与导航框架，但不把三类压成同一个通用页。“监控配置”直达同资源的模板绑定、有效参数、测试与启用，复用同一配置来源。

原型：[prototype/index.html](prototype/index.html)（演示数据，不连后端）。验证记录见 [05-validation.md](05-validation.md)。

## 1. 页面框架（三类共用）

```
┌────────────────────────────────────────────────────────────────────────┐
│ ← 返回数据库        mysql-order-prod            [观测健康: 异常]        │ 身份区
│                     mysql · 10.20.1.15:3306 · 观测于 2026-10-26 11:42  │
│                                    详情成功读取 11:43（非资源观测） 诊断 刷新│
├────────────────────────────────────────────────────────────────────────┤
│ 关联调查 · 最近 2 项  <标题>  更多调查 │ 查看此资源的全部调查            │ 联动区
├────────────────────────────────────────────────────────────────────────┤
│ 概览 │ 监控配置 │ 指标与趋势 │ 健康评分 │ 慢查询 │ 会话 │ 容量 │ …      │ 页签区
├────────────────────────────────────────────────────────────────────────┤
│ 内容区（唯一主滚动区）                                                  │
└────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 规则 |
|---|---|
| 身份区 | 返回按钮保留来源（见 §5）；名称为 H1，长名换行不截断身份；副行固定顺序“类型 · 地址 · 版本/型号”，再一行“观测于”与“详情成功读取（非资源观测）”分开；健康徽章只反映观测证据，未知显示“待确认”而非健康 |
| 页头主操作 | 按类固定：数据库=一键诊断 + 刷新；服务器=一键巡检 + 刷新；网络设备=立即备份（primary）+ 刷新。全部带可访问名称 |
| 联动区 | 一行：关联调查（最近 1 项 + 更多）+ 全部调查链接 + 事件（拟建）+ AI 诊断入口。保持在页签之上，跨页签可见 |
| 页签区 | 保留现有页签集合与顺序；名称只有“采集配置 → 监控配置”这一处更名；页签可横向滚动，键盘支持 ←/→/Home/End |
| 内容区 | 页面唯一纵向滚动区；表格自身局部横向滚动；1280 以下不出现整页横向溢出 |

### 1.1 统一上下文

- 深链接参数全部保留：`?tab=<detail>&id=N`、`metricResource=<type>:<id>`、`metric=…`、`metricFrom/To`、`returnTo=`。
- 详情页内任何跨页跳转必须携带同资源 id；事件/审计/调查链接携带 `resource=<type>:<id>` 与同时间窗。
- **选中身份**：详情标题、副行地址、配置绑定、指标来源与跨模块链接必须来自“被点击的那一行”（`data-id` / 路由 id），不得回退到列表首行；切换资源后旧配置草稿与旧证据不得残留。
- **返回上下文**：从列表进入时记录搜索词、筛选、页码、横向滚动位置与来源按钮；返回后恢复筛选与位置，并把焦点还给来源行操作。
- 时间语义固定三种，永不混用：**观测时间**（last observed）、**最近成功采集**（last success）、**详情读取时间**（本次 API 读取）。旧成功值旁必须显示其时间。

### 1.2 监控配置入口（决策 D-05）

- 页头“监控配置”按钮 → 切到监控配置页签；页签内提供：
  1. 当前绑定模板、版本、digest、配置 revision、策略组与来源（模板目录 / 平台默认 / 策略组 / 本资源覆盖）；
  2. 有效参数（默认 / 本资源覆盖 / 最终值 / 来源），秘密只显示凭据引用；
  3. 可编辑入口“修改模板与参数”：模板选项**按资源类型**取自目录（数据库 / Linux 主机 / 网络设备各自模板），参数草稿只在本页有效；
  4. 有效触发器（只读，P1 后；未接入不显示数量）；
  5. 指标覆盖与缺口、最近配置事件；
  6. 操作：检查兼容性与权限 → 执行试采 → 发布并应用 → 等待正式采集（复用 `metric-configuration` 四步与轮询确认）。
- 只读摘要与编辑态是**同一配置来源**，不做两份状态；未保存修改在离开页签/页面时提示放弃确认（复用 `confirmDiscard`）。
- 三类共用同一流程，但模板、参数、兼容性检查、试采项与影响预览按资源类型渲染，**不得硬编码 MySQL**。
- 权限：编辑能力以 `/api/metrics/config/resources/:type/:id/access` 的 `can_manage` 为准；无权限时保留只读证据并禁用试采/发布，给出权限码原因。

## 2. 状态设计（共享）

### 2.1 五种状态 × 三个层级

| 状态 | 页面级（身份读取失败） | 页签级（该页签读取失败） | 单元格级（列表/表格行） |
|---|---|---|---|
| 正常 | 正常渲染 | 正常内容 | 值 +（旧值显示时间） |
| 无数据 | 资源不存在：“资源不存在或已删除” | 明确“本次未返回记录，不等于健康/无异常” | “无成功采集记录”/“—” |
| 加载失败 | “加载失败”+ 错误摘要 + 重试 + 返回列表 | 页签内错误卡 + 重试，其它页签可用 | “当前状态暂不可用” |
| 部分失败 | — | 分区卡片内部分失败（如 5 项指标 2 项失败）逐项说明，整体不判定为成功 | 多来源拆分：主状态 + 原因 |
| 无权限 | “无权读取该资源”+ 返回；**不渲染名称、地址、健康、联动、页签或任何操作**，也不显示缓存数据 | 页签内“无权读取该模块”，页面身份与其它页签仍可用；不显示旧数据或 0 值 | 操作按钮 `disabled` + 原因 title |

### 2.2 部分失败示例（诊断/指标）

- 头部：`部分成功` 徽章 + “3/5 项采集成功”；
- 逐项列表：每项状态（成功/失败/不支持/待验证）+ 脱敏错误码；
- 底部：不得出现“整体正常”措辞；不得用 0 填充缺测。

### 2.3 采集状态单元格语义（S-08）

一格一个主状态，按优先级：`无权限/不可用` > `应用失败` > `已停用` > `等待首样本` > `采集中` > `正常` > `未知`。原因（blockers）在同一格次级行或悬浮全文显示；不把多个原因用“；”堆成主值。

## 3. 数据库详情（13 页签，保留）

页签：概览、监控配置、指标与趋势、健康评分、慢查询、会话、容量、表结构、索引、SQL 审核、日志、查询分析、AI 诊断。

### 3.1 概览增强

保留“当前需要关注 + 证据缺口 + 资源与能力 + 资源关系”，新增“处理与治理”区块（拟建，P1 后启用）：

```
处理与治理（本资源）
  有效触发器  3 项 · 2 项已触发          [查看监控配置]
  最近事件    2 项未恢复 · 最近 11:38     [在事件中心查看]
  操作审计    最近操作：修改采集配置       [查看审计]
```
未接入时整块显示：“事件与审计尚未接入；这不等于没有事件。当前可用证据见上方缺口说明。”不得显示 0 项。

### 3.2 专业页签保持

- 慢查询/会话：七态状态机（idle/loading/success/error/forbidden/unavailable/expired）保留，空结果文案保留“不能确认采集完整”。
- 容量：历史曲线与当前读取分开标注；结构/索引独立快照说明保留。
- AI 诊断：历史列表、执行轨迹、结果弹窗、转对话保留。

## 4. 服务器详情（10 页签，保留）

页签：概览、监控配置、指标与趋势、配置、诊断、网络、进程、服务、日志、关联资源。

- 概览：关注 / 缺口 / 服务器状态（OS、连接状态登记值、最近状态检查含失败尝试）/ 托管实例。
- 诊断类五页签：顶部固定一条证据条 `本次诊断证据 · 采集于 11:20 · 来源 SSH · 快照不随页签切换更新`；未采集时显示“尚未取得诊断证据”，主操作“采集诊断证据”只在诊断页签（SR-05）与证据条上出现，其它分区页签显示“去诊断页签采集”。
- 关联资源：托管实例列表 + 关系摘要，不重复第二套列表。

## 5. 网络设备详情（6 页签，保留）

页签：概览、指标与趋势、接口、关联资源、配置备份、监控配置。

- 接口：名称/别名搜索 + 运行状态筛选 + 局部横滚表格；保留“标称容量 ≠ 实测流量”“最后发现 ≠ 当前在线”。
- 配置备份：定时设置（启用 / 每日时间 / 最近执行）+ 备份列表（版本 / 时间 / 大小 / SHA-256 / 脱敏状态）+ 摘要弹窗（`app-dialog`，Esc 关闭、焦点返回触发按钮）。
- 立即备份为页头主操作；备份设置属于资源自身配置，不并入监控模板配置。
- **备份权限读写分离**：备份列表、摘要、差异、定时设置读取只需 `network_devices:view`；立即备份与保存定时设置需要 `network_devices:backup`。无 `backup` 时写按钮禁用并说明权限码，读取仍可用。

## 6. 返回与位置恢复（S-10）

| 入口 | 返回目标 | 恢复内容 |
|---|---|---|
| 列表行“详情” | 同类列表 | 搜索词、筛选、页码、列偏好；新增：横向滚动位置与来源按钮焦点 |
| 资源概览下钻 | 资源概览 | `returnTo=` 原路径（现有） |

| 直接粘贴旧链接 | 列表根路径 | 无（保持兼容，不报错） |
| 权限被移除时 | 列表根路径 | 清空上下文并提示 |

## 7. 键盘、焦点与桌面适配

- 页签：`role="tablist"` / `role="tab"` / `aria-selected`，←/→/Home/End 切换，Tab 进入内容区；跳过链接“跳到主要内容”。
- 焦点环：`2px solid var(--ring)`，偏移 2px；表格 `role="region" tabindex="0"` 可聚焦后横向滚动。
- 弹窗（诊断、备份摘要、删除确认、试采流程）：打开聚焦首可操作元素，Esc 关闭，关闭后焦点回到触发按钮。
- 表格行内按钮全部有可访问名称；禁用按钮保留 title 说明原因。
- 长名称：H1 换行不截断；表格单元格单行截断 + 悬浮全文（复用 `.full-value` 模式）；地址与版本等宽显示。
- 宽度：1440×900 主验；1366×768 与 1920×1080 复核。三档均要求主操作不被遮挡、表格只在容器内横滚、页签不换行挤压内容。
- 不新增移动/平板、深色、听读顺序与完整 WCAG 专项（项目范围）。

## 9. 共享组件与权限实现约束

- 原型只读复用 `app-card`、`app-dialog`、`app-badge`、`app-empty-state`、`app-data-table`、`app-form-field`、`app-toast-container` 与 `base.css` / `shared-btn-styles.css`；不复制通用卡片/按钮/徽章/弹窗样式。
- 实施时详情页继续以 `instance-detail` / `server-detail` / `network-device-detail` 为基线修改，不复制原型代码。
- 页签、侧边导航与 `.table-scroll` 横滚容器是布局/交互原语，不属于通用按钮/卡片/弹窗，保留自定义样式但只消费主题 token。
- 权限判断必须读取服务端返回（JWT 权限集、`can_manage`）并在服务端复核；前端 `disabled` 只改善体验，不作为授权依据。完整矩阵见 [06-permission-gates.md](06-permission-gates.md)。
