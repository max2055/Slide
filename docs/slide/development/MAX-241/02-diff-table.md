## E. 入口语义决策（“详情”与“监控配置”）

Issue 要求：“详情”进入完整资源观测；“监控配置”直达同资源模板绑定、有效参数、测试和启用，复用同一配置来源。

**决策 D-05（Chief 已确认）**

- 列表行四操作保持当前业务语义：详情 / 编辑 / 测试 / 删除（S-05）。**不删除“删除”**，也不扩成五个；“监控配置”不占用行内动作。
- “监控配置”作为详情页内的一等入口：
  1. 页头“监控配置”按钮切到监控配置页签；
  2. 页签内“修改模板与参数 / 试采 / 发布”直接复用 `metric-configuration` 编辑态，不跳回列表编辑器；
  3. 批量场景继续由既有“批量绑定采集模板”承担。
- 权限按 06 的实际接口码门控；详情始终 `:view`。

**O-01（已关闭）**：列表行不新增第五按钮；如未来产品坚持，需另立需求并明确替换哪个现有动作。

**O-02（Chief 决定）**：服务器诊断证据采集是写操作（`servers:manage`）。只在“诊断”页签提供一个显式采集主操作；网络/进程/服务/日志分区为主动导航，不自动采集，也不重复采集按钮；权限与审计保留。

**O-03（Chief 决定）**：P1 前不展示“有效触发器”数量（包括模板触发器计数），避免空壳或伪造 0 项。未接入时显示“未接入，不代表没有触发器”；未来示意必须明确标注“非现状”。
