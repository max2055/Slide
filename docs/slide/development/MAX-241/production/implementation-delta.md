## 行操作权限的实施现状纠正

原盘点R-08/06权限表把网络行“测试”与编辑表单“测试连接”混在了一起。实施时逐一核对：行 `testDevice()` 实际调用已有 `POST /api/network-devices/:id/probe`（`network_devices:view`，已纳管设备只读探测）；编辑器 `POST /api/network-devices/test-connection` 才要求 `network_devices:manage`。本轮保留行标签“测试”及原探测能力，未机械照搬原型抬高其权限。网络四动作真实语义为详情/编辑/只读探测/删除，编辑和删除仍按manage门控。

服务器identity读取复用既有canReadResource来尊重已存在的actor resourceBoundary；未新增面向成员的per-server ACL产品模型。三类权限仍由JWT和服务端实时校验最终裁决。
