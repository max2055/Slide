# MAX240-RAW-PAGE 公开原始观测分页（2026-10-29）

范围：在有界接受的 `18e90133b` 之上只增加公开只读原始观测分页；不改 `readWindow` 聚合语义、`formal` 谓词、status/attempts 文案、schema、writer、retention、rollout/scheduler/policy 写入、activate 谓词或必要指标名单，也不改 MAX238 文件。不实现当时阈值、事件快照、停用解绑后授权历史、改名/版本身份、真实采集或容量 SLO。

## 1. 实现

| 面 | 内容 |
|---|---|
| 契约 | `POST /api/metrics/observations`，与 `/api/metrics/query` 并列，复用同一 `verifyToken`。请求：`resource`、`metric{id,semantic_version}`、`dimensions`（默认 `{}`）、`from`、`to`、`limit`（默认 100，最大 1000）、`cursor`。响应带 `contract_version`、资源、指标身份、维度、窗口、`order=observed_at,observation_id`、`total`、`has_more`、有下一页时的 `next_cursor`，以及该页每条的 `id`、`observed_at`、`value`、`unit`、`quality`、`accuracy`、`sources`。不返回凭据、SQL、lineage 或 shadow 行。 |
| 存储 | `MysqlFormalMetricStore.readObservationPage`：同一 REPEATABLE READ 快照内先锁同一 rollout 行，再在同一快照里计算 `COUNT(*)`、取页和 `has_more`。窗口半开 `[from, to)`，不取聚合用的前一条/后一条，不补 0。排序与游标均为 `(p.observed_at, p.observation_id)` 升序，下一页用严格大于该键的 keyset，页界不重复不漏同一时间戳的多行。正式行数超过 `max_rows`（默认 50_000）直接 `QUERY_LIMIT_EXCEEDED`，不返回截断的 `total`。 |
| 授权与游标 | 每次请求（含带游标的后续页）都重新执行 `discover`/`assertAccess`；游标只编码上一页最后一行的键，并带一个绑定 resource、指标 id/语义版本、维度与窗口的摘要，换到其他任一项返回 400 `QUERY_INPUT_INVALID`。401/403/404 沿用查询路由此前的处理。 |
| 前端 | 语义指标视图只加一处「原始观测（正式来源分页）」折叠区：显示当前页、`total`、是否还有更多，用 `next_cursor` 取下一页；不替换曲线、不改窗口内最近可用值的选取与灰化。空页写暂无。401/403/404 清除受保护结果并使用「资源不存在或已不可读；受保护结果已清除。」；400 与 503 等其他失败保留曲线和上一页原始观测，只报这一页失败。 |
