Slide 用户手册

Slide 面向 DBA、SRE 和数据库运维人员。具体页面是否可见取决于当前用户的角色、权限和管理员设置。本文只描述当前控制台中的实际能力；涉及写入、执行或通知的操作应遵循团队变更流程。

开始使用

附件 3：推荐操作路径。按“接入、观察、处置、验证、沉淀”完成一次可追溯的运维闭环。

  1. 在浏览器打开 Slide 地址并登录。
  2. 首次使用时先进入“设置”，确认已配置 LLM 提供商、账号权限和默认语言。
  3. 在“数据库实例”或“服务器”中接入需要观察的目标。
  4. 回到“仪表盘”确认实例健康、容量趋势和告警汇总已经出现。

1. 仪表盘

仪表盘用于快速判断控制面与受管数据库的总体状态。页面汇总实例数、健康状态、当前告警、AI 分析统计和容量趋势；点击统计项可以进入相应的实例或告警工作区。

  1. 从侧栏选择“仪表盘”。
  2. 查看健康、告警和容量卡片，优先处理 critical 或 warning 状态。
  3. 调整容量趋势的时间范围，检查增长速度和异常拐点。
  4. 打开告警或实例详情，继续查看指标与处置记录。

2. 数据库实例管理

实例页面管理受管数据库的生命周期。当前可创建的数据库类型为 MySQL、PostgreSQL、Oracle 和达梦。MongoDB、Redis 与 Elasticsearch 不能作为数据库实例接入。

添加实例

  1. 进入“数据库实例”，点击添加实例。
  2. 选择数据库类型，填写名称、环境、主机、端口、用户名、密码和可选的默认数据库。
  3. 使用“测试连接”确认凭据、网络、主机和端口策略均通过。
  4. 保存后，等待实例被加载并完成首次健康检查。

目标地址必须符合部署时设置的允许网段和端口策略。删除实例只会移除 Slide 中的配置与历史管理关系，不会删除实际数据库。

实例详情

选择实例后可在概览、指标、TopSQL、会话、容量、诊断、Schema、索引、健康评分、SQL 审核和数据库日志等页签之间切换。不同数据库类型的可用功能会因驱动与采集能力而不同。

  1. 先在“概览”确认连接状态、健康评分和最近采集时间。
  2. 在“指标”选择时间范围，查看已采集的 CPU、内存、连接、吞吐或自定义指标。
  3. 在“TopSQL”或慢查询区域定位高开销查询，再进入 SQL 控制台或 AI 分析。
  4. 在“诊断”手动发起故障诊断，并从历史记录比较结论。

3. 服务器管理

服务器页面独立于数据库实例，用于维护 SSH 主机和主机资源观测。可查看服务器清单、聚合指标、单机详情和服务器健康报告。

  1. 进入“服务器”，创建服务器并填写连接信息。
  2. 先运行连接测试，再保存配置。
  3. 从详情页查看 CPU、内存、磁盘、网络与进程相关指标。
  4. 需要时生成服务器健康报告，用于巡检或事件处置。

截图待补充：servers-page.png、server-detail.png。

4. SQL 控制台

SQL 控制台提供实例选择、数据库选择、CodeMirror 编辑器、查询结果、历史记录和执行计划。默认应把它用于只读分析；任何写入意图都要经过组织的审批策略。

  1. 选择一个已授权的数据库实例和目标数据库。
  2. 输入 SQL，先使用 EXPLAIN 或控制台的执行计划能力理解代价。
  3. 执行查询并检查返回结果，避免无条件全表扫描和过大的结果集。
  4. 在历史记录中追溯之前的查询；需要复用时重新审查实例和参数。

SQL 审核与写入

高风险 SQL 可在提交前请求 AI 审核，系统会结合 SQL 文本和实例上下文给出风险信息。审核建议不替代人工判断。需要执行受控写入时，应将请求提交到审批流程，并由具有相应权限的人员批准或拒绝。

5. 告警管理

告警引擎按规则评估已采集的指标。告警页面提供列表、规则、静默、维护窗口、升级、通知状态与 AI 根因分析入口。

  1. 打开“告警”，按级别、状态、实例和时间范围筛选。
  2. 进入告警详情，查看触发值、关联实例、时间线和已关联的事件。
  3. 确认需要继续处置时，添加备注、触发 AI 根因分析或创建/关联事件。
  4. 计划内变更前创建维护窗口；临时抑制明确范围的噪声时使用静默规则。
  5. 处置完成后按团队流程确认恢复，不要仅因告警消失而跳过验证。

维护窗口和静默只影响告警生成或通知，不会停止指标采集。截图待补充：alert-list.png、alert-settings.png。

6. 事件管理

事件将相关告警聚合为可追踪的运维工作项。事件详情可记录调查、备注、根因分析、解决、关闭、恢复验证和事后复盘，并可查看 MTTR 统计。

  1. 从“事件”打开一个待处理事件。
  2. 记录调查结论和已执行动作，避免把结论只保留在即时聊天中。
  3. 按需触发 RCA，并将结果与人工验证分开记录。
  4. 确认服务恢复后执行恢复验证，再解决或关闭事件。
  5. 对重要事件补充复盘，保留影响、根因、改进行动和证据。

7. AI 分析与 Chat 助手

AI 分析覆盖告警根因分析、故障诊断、TopSQL 分析和 SQL 风险评估。Chat 助手支持围绕授权范围内的实例、告警和指标进行连续对话，并通过平台工具检索实时信息。

发起分析

  1. 从告警详情触发 RCA，或在实例详情的诊断区域发起故障诊断。
  2. 等待结果完成后查看结论、证据和建议。
  3. 将建议与实际指标、执行计划和变更记录交叉验证。
  4. 需要执行修复操作时，回到 SQL、审批或事件工作流完成受控操作。

使用 Chat

  1. 打开“Chat”，新建或选择一个会话。
  2. 提出具体问题，例如“列出我有权限查看的异常实例”或“解释这个告警的最近指标变化”。
  3. 等待流式回答；回答可能包含工具查询产生的实时数据。
  4. 不要在会话中输入密码、私钥或其他不应持久化的敏感信息。

Chat 通过 DirectAdapter 而非外部 Gateway 连接。可用工具由当前用户的权限和资源范围决定。截图待补充：chat-interface.png、ai-analysis-result.png。

8. 报表

报表页面用于生成和交付健康、性能、慢查询、容量及服务器健康等报告。可在生成前选择目标、时间范围、格式和通知渠道，生成完成后通过详情或下载接口查看产物。

  1. 进入“报表”，选择报表类型。
  2. 设置实例或服务器、时间范围和输出格式。
  3. 生成报告并等待状态完成；失败时检查详情中的错误信息。
  4. 需要定期交付时配置计划和通知渠道，并查看交付记录或死信。

截图待补充：report-list.png、report-generate.png。

9. 审批

审批页面集中处理需要人工放行的操作，显示审批请求、关联的操作状态、执行事件和重试或取消入口。审批权限与 SQL 执行权限独立控制。

  1. 进入“审批”，筛选待审请求。
  2. 检查 SQL、风险评估、目标实例、提交人和关联操作的执行状态。
  3. 批准、拒绝或批量处理前，确认操作符合变更窗口与回滚计划。
  4. 批准后继续观察操作事件和审计记录；必要时取消或重试。

截图待补充：approval-dashboard.png。

10. 定时任务

“定时任务”支持管理 Cron 表达式、脚本和由 Agent 执行的任务。每次运行都有日志和状态，适合将重复巡检或报告生成纳入受控流程。

  1. 先创建或测试脚本，确认输入与输出符合预期。
  2. 创建定时任务，设置名称、Cron 表达式、关联脚本和执行上下文。
  3. 保存后查看最近一次运行日志；首次上线建议手动运行一次。
  4. 异常时暂停任务，修正脚本或配置后再恢复。

11. 指标注册表、Schema 和索引

指标注册表控制平台可采集和可告警的指标定义。Schema 与索引视图帮助理解对象结构和优化机会，应结合数据库原生工具及变更流程使用。

  1. 在“指标注册表”确认指标适用的数据库类型、采集开关、间隔与计算规则。
  2. 修改指标定义后确认采集能力和仪表盘数据是否正常更新。
  3. 从实例详情的 Schema 区域查看表结构和变更对比。
  4. 从索引区域识别冗余或未使用索引；任何 DDL 前都应审核影响并走审批。

12. 设置、RBAC 与 Agent 管理

设置区提供控制面配置。只有管理员或具有对应权限的用户能看到用户、角色、LLM、AI、提示词、Agent 会话、技能和工具等页面。

RBAC 权限管理

  1. 在“用户与权限”中创建或维护用户。
  2. 创建角色并赋予最小必要的页面与操作权限。
  3. 为用户绑定角色，并配置其可访问的实例范围。
  4. 修改高权限用户后，验证其可见页面和操作边界。

LLM、AI 与 Agent

  1. 在“LLM 设置”添加提供商、模型和密钥，完成连通性验证后启用。
  2. 在“AI 设置”配置自动分析的范围、严重级别、实例白名单和时间窗口。
  3. 在“提示词设置”管理可用的提示词版本；测试后再推广到生产。
  4. 在 Agent 会话、技能和工具页面检查可用能力与历史运行情况。

配置 LLM 密钥时仅输入到受保护的表单；不要把密钥复制到 Chat、脚本内容或审计备注中。截图待补充：rbac-page.png、llm-settings.png、agent-tools.png。

常见问题（FAQ）

为什么看不到某个页面或按钮？

页面导航和操作入口会根据用户权限、实例范围和管理员的可见性配置隐藏。请由管理员检查角色权限和实例授权。

为什么不能添加 MongoDB、Redis 或 Elasticsearch 实例？

当前完整接入链仅支持 MySQL、PostgreSQL、Oracle 和达梦。其他类型没有完整的连接、采集、审批和集成验证路径，因此不能创建。

Chat 为什么连接不上？

确认后端持有 Worker lease、Agent WebSocket 端口 28888 可达，并且浏览器登录令牌有效。当前架构使用 DirectAdapter，不应配置旧的 Gateway 地址。

AI 分析没有结果怎么办？

检查 LLM 设置中是否存在已启用且可用的提供商，再检查网络、模型名和密钥。AI 建议应与数据库指标和人工诊断交叉验证。

告警消失后可以直接关闭事件吗？

不建议。应先完成恢复验证，记录确认依据；必要时补充根因与复盘，防止短暂恢复掩盖未解决的问题。
