Slide 系统架构

Slide 是面向数据库运维场景的 AI Agent 平台。系统把受管数据库、服务器资源、告警事件、SQL 审核、审批执行、报表和 AI 分析集中在一个控制面中：前端负责交互和可视化，后端负责认证、资源治理和运维闭环，内置 Agent 引擎通过 DirectAdapter 提供流式对话和工具调用能力。

当前架构已从早期外部 OpenClaw Gateway 演进为后端自管理的 DirectAdapter WebSocket 传输层。Agent 不直接绕过控制面访问资源，而是通过平台工具、RBAC、目标地址策略、审批和审计链路完成受控分析与执行。

模块职责

前端控制台

  • 业务工作区：仪表盘、数据库实例、服务器、SQL 控制台、告警、事件、审批、报表和定时任务。
  • AI 交互：Chat 会话、工具调用流、AI 分析结果、Agent 运行状态和历史会话。
  • 设置区：LLM 提供商、提示词、AI 分析策略、评分权重、用户、角色、技能、工具和系统偏好。
  • 文档查看器：从受保护的 /api/docs 接口加载 HTML 文档，在前端净化后渲染。

后端控制面

  • 认证与授权：JWT、Actor Context、RBAC、实例级资源访问和 WebSocket 会话校验。
  • 数据库服务：实例 CRUD、连接池、健康检查、指标采集、慢查询、活动会话、容量和执行计划。
  • 告警与事件：规则评估、静默、维护窗口、升级、通知、事件聚合、调查、恢复验证和复盘。
  • SQL 治理：SQL 审核、只读/写入边界、审批流、操作状态机、重试、取消和审计记录。
  • AI 平台：LLM 提供商配置、提示词版本、技能加载、工具目录、分析记录和 Agent run 记录。
  • Worker 运行时：指标采集、告警评估、定时任务、工作流 outbox、通知交付和会话清理。

Agent Core 与平台工具

@slide/agent-core 提供通用 AgentRunner、上下文管理、工具调用和 LLM Provider 抽象。后端的 DirectAdapter 负责把它接入 Slide 的认证、会话、工具目录和审计策略。工具不是无限开放的 Shell，而是受当前用户角色、资源范围、工具策略和目标数据库策略限制的平台能力。

告警 RCA 分析

RCA 不是单纯让模型“凭经验猜”。系统会把告警、实例健康摘要、实时指标、历史趋势、慢查询和可用服务器指标作为上下文，要求 Agent 输出根因假设、证据、置信度和建议操作。当前可稳妥描述为“多源运维上下文关联分析”，而不是完整覆盖应用、缓存、搜索和链路追踪的跨系统因果分析。

告警上下文级别、触发值、实例、时间窗口。
实例指标实时快照与 24h 趋势，定位跳变点。
SQL 证据慢查询、TopSQL、执行计划和连接信息。
服务器资源CPU、内存、磁盘、负载和相关告警。
分析结果假设、证据链、建议、验证方法。

受控写入与审批

写操作必须经过 SQL 风险评估、审批和操作状态机。审批通过后，执行过程会记录目标数据库、提交人、审批人、操作状态、重试次数和审计日志；失败、取消、重试都作为独立状态进入运维记录。

安全边界

边界机制目的
身份认证JWT、刷新令牌、WebSocket auth 首帧和心跳复验保证 HTTP 与 Agent 会话都绑定有效用户。
权限控制RBAC、实例级访问、工具策略限制用户能查看和操作的资源。
目标数据库目标地址策略阻止特殊/元数据地址；端口仅校验为有效 TCP 端口。
目标服务器与网络设备目标地址策略DNS 解析固定并阻止特殊/元数据地址；端口仅校验为有效 TCP 端口。
凭据保护ENCRYPTION_KEY、密钥格式校验、生产默认值阻断保护数据库和 LLM Provider 凭据。
写入治理SQL 审核、审批、操作状态机、审计日志把高风险动作纳入人工确认和可追溯流程。
出站访问通知 URL 策略、SSRF 防护、提供商配置限制 Webhook 和 LLM 调用的出站风险。

外部依赖

依赖是否必需说明
MySQL 控制面必需启动前必须可连接；Schema migration 在服务启动时执行。
受管数据库按需当前实例纳管支持 MySQL、PostgreSQL、Oracle、达梦。
服务器 SSH按需用于服务器资源观测和健康报告。
LLM 提供商使用 AI 功能时必需优先使用控制台启用的提供商；没有可用配置时才回退环境变量。
SMTP / 飞书 / 钉钉 / 企业微信 / Webhook按需用于通知渠道；生产环境需完成渠道配置、连通性验证和出站策略校验。

架构演进说明

旧文档中提到的外部 Gateway、Redis/MongoDB/Elasticsearch 数据层和部分 OpenClaw 前端分层属于早期设计或已过时内容。当前实现以 server.ts、src/adapter/direct-adapter.ts、packages/agent-core、前端路由和数据库迁移为准。后续如果引入新的受管资源类型或链路追踪、日志搜索、缓存诊断等能力，应同步更新本页的架构图、数据流和外部依赖。
