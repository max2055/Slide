Date: 2026-08-26

## Scope

The v0.10 implementation covers the existing database workflows, Kylin OS,
Red Hat Enterprise Linux, CentOS servers, and Huawei VRP network devices.
Network-device operations are read-only: SNMPv3 collection, device and
interface evidence, alerts, resource relations, and encrypted SSH configuration
backups. Configuration push, restore, arbitrary CLI, SNMP SET, auto-discovery,
Windows, and non-Huawei devices remain out of scope.

## Huawei Hardware UAT

Status: **BLOCKED BY EXTERNAL ENVIRONMENT**.

No real Huawei VRP device, target model/VRP release, vendor MIB fixture, SNMPv3
credential, and registered SSH host key were available in this execution
environment. Fixture and contract tests therefore prove implementation and
fail-closed behavior only; they do not prove model-specific enterprise CPU,
memory, or temperature OIDs on a production device. Those metrics remain
`unsupported` until the target hardware UAT is completed. The UAT must verify
SNMPv3 success/failure, timeout, reboot and counter reset behavior, interface
error/drop alerts, host-key enforcement, encrypted backup hashing, and audit
permissions before those capabilities are advertised as hardware-verified.
