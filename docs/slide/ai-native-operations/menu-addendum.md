# V1 菜单与导航决定

- 工作空间：关注事项、AI 工作空间、普通对话。关注事项可选为首页，保留用户既有默认首页；资源概览保留为关注事项内视图切换。
- 资源管理：数据库实例、服务器、网络设备。
- 运维作业：事件中心、资源诊断、SQL 工作台、定时任务、报表。可信运维知识属 V2。
- 治理：审批、审计；行动中心属 V3，V1 隐藏未实现入口，不把原型 future 页当作已实现功能。
- 底部入口：平台健康、帮助与反馈、设置。系统角色 System Agent / Ops Agent 不单列为一级菜单。
- 设置：用户与 RBAC；AI Provider、模型场景路由、Profiles、Prompts、Skills、Tools；调查策略；指标/告警/通知；用量与成本；源码/部署；外观/默认首页。调查策略从原型顶层演示入口归入设置。
- 既有资源、诊断、SQL、任务、报表、审批、审计及设置能力保持路由兼容；原型未展开的页面不代表删除。
- AI 工作空间在 1600px 展开调查列表/执行协作/证据成果；1024px 证据抽屉；390px 单栏可访问。普通对话仍可直接输入，不强制创建调查。

菜单重组不授权重写所有既有业务页；复用现有导航、权限和共享组件，校验可见性及旧深链。
