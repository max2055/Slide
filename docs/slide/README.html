Slide 项目文档

Slide v0.10 是面向 DBA、SRE 和运维团队的 AI 原生基础运维助手。它将数据库、Kylin/RHEL/CentOS 服务器和华为 VRP 网络设备的监控、告警、关系影响分析、只读诊断与加密配置备份集中到一个控制台，并对高风险操作保留权限、审批和审计边界。

附件 1：Slide 平台全景。REST 管理链路与 Agent 对话链路分离，所有受管资源操作均回到控制面策略。

当前版本要点

  • 前端使用 Lit 3.3 和 Vite；后端使用 Fastify 与 TypeScript。
  • AI 引擎使用内置 @slide/agent-core 和 DirectAdapter，不依赖外部 OpenClaw Gateway。
  • Agent WebSocket 默认监听 ws://127.0.0.1:28888；连接后必须先发送 JWT 认证帧。
  • 可纳管 MySQL、PostgreSQL、Oracle 和达梦数据库；MongoDB、Redis、Elasticsearch 不是可创建的数据库实例类型。
  • Agent 可结合数据库、服务器和网络设备的告警、实时观测、关系和数据质量生成跨资源诊断建议。
  • 网络设备仅支持华为 VRP 的 SNMPv3 只读观测和 SSH 加密配置备份；不提供任意 CLI、SNMP SET、配置下发或恢复。
  • LLM 设置支持 Anthropic、OpenAI 兼容接口、阿里云百炼、DeepSeek、MiniMax、GLM 和 Ollama。

快速启动

运行时要求 Node.js 20 或更高版本，以及可访问的 MySQL 控制面数据库。

pnpm install

# 终端一：后端 API（默认 :3000）
cd apps/db-ops-api
npx tsx server.ts

# 终端二：前端开发服务器（默认 :5173）
cd frontend
npm run dev

浏览器访问 http://localhost:5173。开发环境初始化后的默认管理员为 admin；生产环境必须使用 INITIAL_ADMIN_USERNAME 和 INITIAL_ADMIN_PASSWORD 创建初始管理员，且不得使用默认凭据。
