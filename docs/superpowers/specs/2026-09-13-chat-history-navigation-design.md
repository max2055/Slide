# Agent 历史对话刻度导航

依据当前会话已确认需求实施，不新增设计批准步骤。

- 当前会话左侧等长短刻度，每次用户提问一个节点，工具/日志归入该轮。
- 悬停目标最长、相邻刻度渐进展开，显示用户问题和助手可见文本片段；离开恢复。左端和纵向位置不移动。
- 点击切换正文渲染段并定位、高亮；滚动更新当前位置，提供回到最新入口。
- 导航独立 Shadow DOM 组件，预览复用 app-card，颜色/间距/圆角使用主题 token。键盘可浏览、Enter 跳转，支持 reduced motion。
- REST 历史增加可选游标分页，保持旧调用兼容和 actor 授权边界。客户端顺序读取全部页，防止切换会话后过期结果覆盖。正文保留约 200 条分段渲染，避免一次渲染完整历史。
- 空会话隐藏，长导航内部滚动，预览不越出容器；历史阅读期间新输出不抢夺位置。

验收：分组和分页回归、权限边界、浏览器实际渲染/悬停/跳转/换会话/流式输出验证、受影响模块测试及最终前后端门禁。仅修改直接支持本需求的代码，不做无关重构。硬预算未设定；实际 token 遥测不可用；不使用子代理。
