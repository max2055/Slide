Slide 当前版本项目范围

生效日期：2026-10-22。来源：用户确认本轮范围建议，并要求写入项目范围。本文约束当前版本的设计、实施、原型与验收，不宣称拟建能力已经实现。用户后续明确调整优先；通用技能清单不扩大本范围。

1. 使用环境与验收边界

方面 本版本约定
目标设备 桌面浏览器。以 1440×900 为主要设计尺寸，1366×768 检查主要操作可达，1920×1080 检查空间利用
窗口缩放 支持上述桌面范围内调整窗口；复杂表格允许容器内横向滚动，主操作、弹窗和固定操作区不能遮住内容。范围外尺寸不纳入本版专项
浏览器 当前稳定版 Chrome / Edge；不做 Safari、Firefox、旧版本及完整操作系统/浏览器组合专项
语言 中文界面，允许必要的技术英文；不建设语言切换、翻译、多语言排版和额外区域格式矩阵。保留业务要求的准确时间、时区、单位
外观 只设计和验收浅色蓝色主题，复用共享组件和 token
代表状态 覆盖主要业务路径、关键异常及约定桌面尺寸，不穷举全部页面×状态×分辨率×缩放截图组合

2. 本版本不投入的工作

  1. 手机、平板专项布局，触控优化、横竖屏及移动断点。
  2. 暗色模式、多主题、换肤、用户自定义配色/字体/导航布局、可拖拽仪表盘。
  3. 屏幕阅读器、听读顺序、播报专项，以及完整 WCAG 合规认证和专项测试矩阵。
  4. Safari、Firefox、旧浏览器与跨平台兼容矩阵。
  5. 国际化、语言切换和多语言内容维护。
  6. 装饰性动画、复杂转场、3D、无业务价值的动态效果；加载、进度及操作反馈保留。
  7. 打印专用布局、电视大屏及专门的全屏展示模式；业务已有/明确要求的报告导出不因此取消。
  8. PWA、安装式 Web 应用、离线业务操作与浏览器本地业务同步；断线后的错误反馈和服务端任务结果核对仍需保留。
  9. 为同一任务同时建设多套等价操作路径、全局快捷键体系或命令面板；保留必要的上下文入口和基本键盘操作。
  10. 穷举视觉自动化组合；只按风险和实际改动检查关键页面、状态与约定桌面尺寸。
  11. Zabbix 模板文件导入/转换、表达式语法兼容、兼容报告/矩阵、上游自动同步、Zabbix Agent/Proxy 接入及 Zabbix 后端部署。未来若需要，单独立项，不预建通用兼容框架。

排除专项投入不等于删除已有功能。不顺手清理未触达的旧主题、移动样式或其他产品能力；不因此添加禁止用户使用的流程。

3. 必须保留的基本质量

  • 清楚的文字、对比、表单名称、按钮反馈、基本键盘操作、弹窗焦点管理及关闭后恢复；不把取消完整无障碍专项解释成可以损害日常可操作性。
  • 加载、空数据、无权限、失败、部分失败、超时、未知回执和可恢复路径；不能用健康/零值掩盖未知。
  • 长名称、表格局部滚动、筛选分页，以及目标数据量下的查询和采集性能。性能与容量仍按真实目标定义，不因取消穷举视觉测试而省略。
  • 真实数据、权限隔离、凭据保护、幂等、危险操作确认、审批、审计及恢复验证。
  • 尽量选择/筛选、自动带入上下文和生成草案；仅缺少信息或需要自定义时手工输入。
  • 所有开发 gate 和真实业务验收仍按改动与仓库规则执行；原型不能替代生产验证。

4. 监控与运维的确定方向

  • 纳管对象无 Agent 采集：优先复用现有 SQL、SSH、SNMP，HTTP 等方式仅在有已注册实现时提供。这里的 Agent 指目标侧监控采集代理，不影响 Slide 的 AI Agent 运行时。
  • 人工创建和维护 Slide 原生模板，可参考 Zabbix 的指标选择、触发/恢复及发现机制；不导入它的配置文件或承担其运行兼容。
  • 模板包含监控项、触发器、参数、发现定义等；资源从当前全部授权模板中选择，按实际能力校验，不写死模板名称。
  • 监控项从已注册可采集指标中选择，自动带入稳定标识、单位和字段映射。新增名称不等于新增采集能力；缺实现时阻止应用并解释原因。
  • 资源管理保留资源概览、网络设备、服务器、数据库四菜单，概览保留四子标签；发现位于模板内。
  • 事件中心不保留重复的“规则与策略”标签。事件详情展示当时的触发规则快照及来源；通知投递展示发送记录，通知配置复用现有统一入口。静默/维护提供就近入口，不新增空壳策略中心。
  • 资源及平台调查统一在 AI 工作空间，以故障排查—授权处置—恢复验证为首版重点；不新增问题中心、运维工作台或独立跨资源诊断菜单。
