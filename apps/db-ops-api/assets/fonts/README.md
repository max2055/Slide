# PDF 报表字体

`NotoSansCJKsc-Regular.otf` 随源码、API 镜像和代码发布包交付，PDFKit 在运行时按模块相对路径加载并嵌入所需字形；不依赖宿主机字体或运行时下载。标题、元信息及正文共用此字体，以字号区分层级。

来源：Noto CJK，固定版本 `Serif2.003` 的 Sans 目录（该仓库标签包含 Sans 字体）：

- https://github.com/notofonts/noto-cjk/blob/Serif2.003/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- https://github.com/notofonts/noto-cjk/blob/Serif2.003/Sans/LICENSE
- 字体 SHA-256：`2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`

字体未修改，按 SIL Open Font License 1.1 分发，完整许可见 `OFL.txt`。该简体中文字体覆盖平台常用中文、中文标点和 ASCII；不承诺覆盖所有 Unicode 字符。
